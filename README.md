# Aditya Guest Directory

V1 mobile-first guest directory for a personalized hotel QR experience.

## Current scope
- Aditya Patil personalized welcome
- Food & Beverage
  - IRD
  - Intermezzo
  - Arbor Kitchen
- Contact Aditya
  - Call
  - WhatsApp
  - Request Assistance

## Future-ready structure
The data layer already separates staff, restaurants, categories, menu items, hotel information, city places and QR entities so the later admin panel can manage content without redesigning the guest UI.

## Run locally
```bash
npm install
npm run dev
```

## Deploy
Import this repository/project into Vercel. The current app is frontend-only and uses local data until the admin/backend layer is added.
